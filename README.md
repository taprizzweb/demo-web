# Picnic in Paris — website

One-page marketing and booking site for **Picnic in Paris**: luxury, styled picnics on the
Champ de Mars, steps from the Eiffel Tower.

- Static site: `index.html`, `styles.css`, `main.js`. No build step; deploy to Vercel/Netlify as-is.
- Cinematic Eiffel Tower header video (CC0, Wikimedia Commons) with a photo slideshow fallback.
  See `assets/video/README.md` to self-host it.
- Bookings go to WhatsApp (+33 6 05 97 49 68) with a pre-filled message from the form.
- Photos and business details are from the Picnic in Paris Google Maps listing.

Run locally:

```bash
python3 -m http.server 8000
```
