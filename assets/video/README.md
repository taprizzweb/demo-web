# Hero video (optional self-hosting)

The header plays the CC0 clip "Sunset on Eiffel Tower in Paris" by Mythomen,
streamed from Wikimedia Commons:
https://commons.wikimedia.org/wiki/File:Sunset_on_Eiffel_Tower_in_Paris_-_Vimeo.webm

For the fastest, most reliable header, download the two transcodes from that page
and save them here as:

- `eiffel-sunset-1080.webm` (1080p VP9)
- `eiffel-sunset-720.webm` (720p VP9)

The site tries these local files first, falls back to Wikimedia, and if neither
plays it shows a slideshow of the business's own Eiffel Tower photos.
